# Sprint record template

Copy this into an agreed epic/sprint folder; fill the fields using actual decisions and evidence.

## Identity and status

- Epic and sprint ID:
- Goal:
- Agreed dates, or explicitly labeled retrospective period:
- State: proposed / in progress / implemented / verified:
- Related iteration log:

## Scope

List story IDs, acceptance criteria, exclusions and unresolved product decisions. Do not add assumed MISO policies.

## Implementation and verification

Link each story's `implementation-plan/US-NNN-implementation-plan.md` and `sprint-NN-tests-US-NNN.md`. Record actual file changes, commands, results, failures, fixes and remaining limitations. Pending checks remain pending until run.

## Outcome

Record delivered behavior, deviations from scope, unresolved work and links to the corresponding change log. A completed sprint record does not imply production acceptance.
