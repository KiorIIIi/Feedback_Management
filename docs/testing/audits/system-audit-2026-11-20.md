| A1 | Medium | `backend/app/Providers/AppServiceProvider.php:20` | The `portal-login` limiter hashes `mb_strtolower(trim((string)$r->input('email')))`. Empirically confirmed twice: an unauthenticated `POST /api/login` returns **500** (`ErrorException: Array to string conversion`), and the exception is raised while the limiter callback is evaluated, so **neither** the account nor the IP counter engages (an isolated execution of the real middleware stack measured 12 malformed requests → 12 exceptions, IP-bucket attempts 0; a well-formed control incremented normally). ## Disposition after this pass

- **Fixed in the first pass (test-suite redness blocking verification):** A2 (roles.spec and assistant-setup.spec updated to the recorded 017 and 010/014 behavior, including the removed `.connection` status element) and A3 (portal.spec returns to a desktop viewport before the sidebar sign-out). A12 — `GET /api/assistant/keys` moved out of the assistant-admin write limiter, with a regression test.
- **Fixed in the first pass (introduced by the new feature, caught by the suite):** the share panel initially rendered "Collection source · shared link" as a "Not supplied" row on legacy feedback, breaking `feedback-revamp.spec.ts`. The row now renders only when a label exists.
- **Fixed in the second pass (user-authorized remediation, see [change 022](../../changes/iteration-03/sprint-03/022-system-audit-remediation.md)):** A1, A4, A5, A6, A7, A8, A9, A10, A13 (metrics fully; summary columns narrowed, full rewrite deferred pending measurement), A14, A15.
- **Deferred:** A11 — draft preservation across re-authentication awaits a product decision on what is worth persisting and for which account.

## Reviewed and verified sound

- **`scripts/migrate-public.php` targets the correct database in the normal case.** A reviewer suspected the validated runtime metadata was never applied to the effective connection; verification showed `scripts/public-runtime.php` loads `runtime.json` into the environment *before* Laravel bootstraps, and Dotenv (immutable) does not overwrite those values, so the operator credentials are then applied only for this CLI process. The remaining conditional gap — no rejection of a cached configuration — is reported as finding A15.
- MCP tool authentication chain: credentials check expiry, revocation, active administrator authority and office binding; only five read tools are exposed; no SQL/shell/account-admin surface. An executed synthetic lifecycle probe confirmed the job number, original description and revision history survive clarification→completion→evaluation, internal notes stay hidden from requesters, and duplicate verified evaluations are rejected.
- `ProductionConfiguration::assertSafe()` rejects debug mode, unsafe URLs/cookies, wildcard proxies, demo seeding and synchronous queues outside local/testing.
- Feedback privacy scoping: independent feedback is routed to MISO (not every office), requesters see only their own, personnel receive 403; unverified job numbers grant nothing; `GeneralFeedback::submit()` whitelists columns.
- Report downloads are owner- and office-checked with per-user throttling; queue retry window exceeds the job timeout; request updates lock the row before the version check and commit data, history and audit entries in one transaction; job numbers are ULIDs under a unique constraint.
- Session cookies are HttpOnly/SameSite=Lax; the test bootstrap rejects unsafe database targets and cached configuration; `Storage::fake('local')` isolates test exports.
- Fresh `npm --prefix frontend audit --package-lock-only` reports zero known vulnerabilities across the 166 frontend dependencies.
- Documentation links and heading anchors pass `scripts/check-docs.py`.
