# Unified assistant and collapsible sidebar

15 November 2026. MCP Assistant now contains connection settings, API keys, OAuth clients and local demo tools on one page with section links. The old assistant settings URL redirects to the unified page. The duplicate management navigation entry is removed.

Desktop administrators can collapse the sidebar to an icon rail and expand it using the header button. Navigation retains accessible names and hover titles. Mobile keeps its existing drawer. Collapse state is saved in this browser's local storage and restored after reloads. If storage is unavailable, the toggle still works for the current session.

No backend authorization or MCP permissions change.
