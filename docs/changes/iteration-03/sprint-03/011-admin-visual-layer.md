# Admin visual layer

15 November 2026. User-directed styling uses warm neutrals, a humanist system font stack, monospace record values, a connected summary strip emphasizing Open, compact ruled tables, sticky table headers and flat status tags. Routes, data and actions remain unchanged. Compact sidebar mode retains labels. No libraries added.

Mobile refinements include coarse-pointer 16px form text, 44px controls, scroll containment, dynamic drawer height and viewport safe-area support. Browser emulation does not verify physical-device keyboard, safe-area or touch behavior; those checks remain outstanding.
