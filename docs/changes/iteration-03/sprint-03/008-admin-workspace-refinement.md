# Admin workspace refinement

14 November 2026. Shared admin styles reduce decorative emphasis across the dashboard, requests, personnel, feedback, reports and assistant screens. Summary cards become a compact divided row; headings and tables use clearer text contrast and consistent sizing. Public and requester surfaces retain their existing styling.

The dashboard removes the latest-request banner and puts the request table before an expandable trends section. Existing reporting controls and chart data remain available. Connection settings prioritize MCP setup and API keys, with disabled provider settings collapsed.

Verification: TypeScript and Vite production build passed. Browser checks cover desktop (1440px) and mobile (390px) admin routes. This is a visual refinement, not a change to authorization or workflow policy.
