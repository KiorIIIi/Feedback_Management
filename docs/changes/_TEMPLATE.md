# Change record template

Create a new file in `docs/changes/iteration-NN/sprint-NN/` using the next available three-digit sequence and a descriptive name. Keep this template unchanged; fill the new record with actual information.

## Identity

- Iteration:
- Sprint:
- Change number and title:
- Date:
- State: proposed / in progress / implemented / verified / documentation-only:
- Request or reason:

## Changes

Record the added or changed behavior, affected files and relevant decisions. Link to existing plans and requirements instead of duplicating them.

## Verification

Record only checks actually run, their results, failures and limitations. For documentation-only work, check links and content; do not imply application tests ran. Link to existing dated evidence where appropriate.

## Remaining work

Record unresolved decisions, deferred work and known limits.

Add this record to its sprint's `sprint-overview.md`. Add new sprint folders to the iteration's `iteration-overview.md` and new iteration folders to the changes index. Keep all new Markdown files within `docs/`.
